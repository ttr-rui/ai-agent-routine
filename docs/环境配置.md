# 环境配置指南（含排错对照表）

> 看完这份能独立完成：拿 key → 配 `.env` → 跑起来 → 出错知道去哪查。

## 1. 三种运行方式速查

| 场景 | 命令 | 需要 key | 需要联网 |
|---|---|---|---|
| 本机没有 Python / 不想配环境 | `powershell -ExecutionPolicy Bypass -File .\run.ps1 demo` | 否 | 否 |
| 自己有 Python 3.10+ | `pip install -r requirements.txt` → `python main.py` | 真实模式需要 | 装依赖时需要 |
| 网页版 | `run.ps1 web` 或 `streamlit run ui/app.py` | 同上 | 同上 |

## 2. 申请 LLM_API_KEY（以 DeepSeek 为例）

1. 打开 https://platform.deepseek.com/ → 注册并登录。
2. 左侧「API keys」→「创建 API key」→ **立即复制保存**（只显示一次）。
3. 平台需有余额才能调用，先充值最低档即可，本作业一次演示通常只花几分钱。
4. 也可以改用任何 OpenAI 兼容服务（通义千问、智谱、OpenAI、校内代理），只需同时改 `LLM_BASE_URL` 与 `LLM_MODEL`。

## 3. 配置 .env

```bash
cp .env.example .env        # Windows 手动复制改名也可以
```

最小可用配置：

```ini
LLM_API_KEY=sk-你的真实key
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
USE_MOCK_LLM=0
```

**三条铁律**
- `.env` 永远不进 Git（已在 `.gitignore`），截图/录屏时别把它拍进去。
- 改完 `.env` 必须**重启进程**，配置是启动时读取的。
- `LLM_MODEL` 必须支持 function calling，否则 Agent 只会聊天不会调工具。

## 4. 验证配置是否成功

```bash
python main.py
# 看到「✅ MCP 已连接，可用工具：add_task, ...」即成功
# 输入：帮我添加任务：明天交作业   → 应出现 🔧 add_task 执行轨迹
```

没有 key 也能先验证架构：

```bash
# Windows PowerShell
$env:USE_MOCK_LLM="1"; python main.py
# macOS / Linux
USE_MOCK_LLM=1 python main.py
```

## 5. 可选组件

| 组件 | 安装 | 用途 |
|---|---|---|
| 语音合成 | `pip install edge-tts` | 回复播报（UI 侧栏开关） |
| 语音识别 | `pip install faster-whisper av==13.1.0` + `python scripts/fetch_asr_model.py` | 🎤 说话转文字。模型文件不在仓库内（138MB 超 GitHub 上限），执行脚本下载到 `models/whisper-base/` 即可离线使用；⚠️ PyAV 必须锁 13.x——14+ 移除了 `metadata_errors` 参数，ASR 会永远「没听清」（BUG-12）；浏览器需允许 localhost 使用麦克风 |

| MCP 调试器 | 需本机有 `npx`，然后 `mcp dev server/task_mcp_server.py` | 不写前端也能手测 8 个工具 |

## 6. 报错对照表

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `pip 不是内部或外部命令` | 系统 python 是微软商店占位符 | 用 `run.ps1`，或装真 Python 并勾选 Add to PATH |
| `在此系统上禁止运行脚本` | PowerShell 执行策略 | 命令前加 `powershell -ExecutionPolicy Bypass -File` |
| `ModuleNotFoundError: mcp.server.fastmcp` | 装成了 mcp 2.x | `pip install "mcp>=1.9.0,<2.0.0"` |
| `未配置 LLM_API_KEY` | 没建 .env 或 key 是占位符 | 按第 3 节配置；或先 `USE_MOCK_LLM=1` |
| 回复里编造任务、没有执行轨迹 | 模型不支持工具调用 | 换 deepseek-chat / gpt-4o-mini / qwen-plus |
| `attempted relative import...` | 用 `python -m` 方式启动 Server | 直接 `python server/task_mcp_server.py` |
| 中文乱码 | Windows 控制台编码 | 先 `chcp 65001`；Client 已自动注入 `PYTHONIOENCODING=utf-8` |
| 看板看不到 Agent 加的任务 | 两端 DB 路径不一致 | 确认 `TASK_DB_PATH` 没被单独改过，Client 会注入绝对路径 |
| 语音识别一直转圈 | 首次加载模型到内存（CPU 上约几秒）| 稍等即可；模型文件已在仓库内，无需联网 |
| 录音清晰但提示「没听清」 | ① 服务没重启（旧进程内存里还是 14+ 的坏 av 库）② av 装成了 14+ | 重启 Streamlit；`pip install "av>=13,<14"` 后重启（BUG-12） |
| 改了代码没生效 | Streamlit 缓存 / 进程未重启 | 网页右上角 ⋮ → Rerun；CLI 直接重启 |
