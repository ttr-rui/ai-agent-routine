## 用例 1：添加任务 ⚙️

- **前置**：`USE_MOCK_LLM=1`（或真实 key），空数据库
- **步骤**：对 CLI/网页说「帮我添加任务：明天交智能体作业，很急」
- **预期**：执行轨迹显示 🔧 `add_task`，参数 `priority=1, due_date=明天`；回复含任务编号；`due_date` 被归一化成**明天的真实日期**（如 2026-10-25）；`data/tasks.db` 的 `tasks` 表多一行、`status='pending'`
- **自动化**：`test_e2e.py` 用例 1（同时校验 MCP 连上 8 个工具）

## 用例 2：查未完成任务 ⚙️

- **步骤**：「帮我看看还有哪些没做完的待办」
- **预期**：轨迹显示 `list_tasks` 且参数 `status="pending"`；回复里能看到用例 1 加的任务标题
- **反例**：已完成的任务**不应**出现在列表里

## 用例 3：标完成 ⚙️

- **步骤**：「1号做完了」
- **预期**：轨迹显示 `complete_task(task_id=1)`；回复带 ✅；数据库 `status` 变 `done`；用例 2 的查询不再返回它

## 用例 4：删除 ⚙️

- **步骤**：先加一条「临时测试用的任务」，再「删除N号任务」
- **预期**：轨迹显示 `delete_task(task_id=N)`；直接查 SQLite 确认该行已消失（不是软删除也行，以查库为准）
- **反例（真实 LLM 下要人工验）**：说「删掉那个东西」这种模糊指令时，Agent 应先查列表/反问确认，而不是瞎猜 id

## 用例 5：闲聊 ⚙️+🖐️

- **步骤**：「你好呀，今天天气怎么样」
- **预期（⚙️ 离线模式）**：链路不崩、非空回复（Mock 兜底成一次查询属预期）
- **预期（🖐️ 真实 LLM）**：自然语言聊天回复，**不编造任务、不乱调 add/delete**
- **这是老师最容易抽查的一条**：演示时主动说一句闲聊证明「能说」

## 用例 6：多轮指代 ⚙️+🖐️

- **步骤（⚙️）**：先查列表拿到编号 → 直接说「N号做完了」→ 断言 complete 成功 + `messages` 表已有历史
- **步骤（🖐️ 真实 LLM）**：「添加任务：买牛奶」→「刚才那个任务提前到明天」→ 应更新**牛奶那条**而不是新建
- **预期**：Agent 使用上一轮上下文；`AGENT_HISTORY_TURNS` 内的记忆生效
- **注意**：超过 20 轮后早期对话会被摘要压缩，指代失效属正常，不是 bug

## 用例 7：重启后数据仍在 ⚙️

- **步骤**：加一条「重启存活测试XYZ」→ 完全退出进程 → 重新启动 → 查未完成
- **预期**：新进程能查到旧任务（SQLite 持久化）；对话记忆 `messages` 表也在
- **这是「多轮记忆」加分项的直接证据**，演示视频里值得专门给一个镜头

## 用例 8：语音输入 🖐️（加分项）

- **前置**：`pip install edge-tts faster-whisper`；浏览器允许麦克风
- **步骤**：网页端按住 🎤 说「提醒我明天下午三点开会」→ 松开 → 观察转写文本与回复；再点 🔊 听 TTS 播报
- **预期**：转写文本出现在输入框并走正常对话链路；点播报能听到中文语音
- **降级验收**：没装依赖时按钮隐藏、页面不崩（`test_e2e.py` 用例 8 已自动验证 ASR 垃圾输入不崩 + TTS 降级）
